# План стабилизации и реализации рабочего MVP Video Cutter Pro

Комплексный инженерный план по устранению крашей интерфейса и бинарных sidecar-процессов, реализации надежного двухфакторного поиска хайлайтов, автоматическому центрированию лица персонажа при кропе 9:16, формированию удобной структуры директории проекта и оптимизации GitHub Actions сборки (строго < 2 ГБ).

### User Review & Critical Decisions

> [!IMPORTANT]
> В план интегрированы три новых обязательных требования пользователя:

- **Confirmed Decision 1 (GitHub CI & Лимит 2 ГБ)**: В сборку под Windows включаются минимально необходимые для инференса CUDA runtime DLL (`whisper.dll`, `ggml.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`, `cudart64_12.dll`), а базовые модели поставляются в квантованном виде (ggml-base ~148 МБ). Тяжелые VLM модели исключаются из бинарного установщика и скачиваются по требованию. Финальный размер NSIS-установщика и zip-архива в GitHub Actions составит ~350–550 МБ, что с запасом укладывается в лимит 2 ГБ.
- **Confirmed Decision 2 (Структура папок проекта и понятные имена файлов)**: При обработке видео рядом с исходником (или в выбранной папке) создается изолированная директория проекта `[ИмяВидео]_Проект/`, внутри которой создается папка `Готовые клипы/`. Файлы именуются в человекопонятном формате: `Клип 01 [00m15s - 00m45s].mp4`, `Клип 02 [01m12s - 01m38s].mp4`, что позволяет сразу зайти и загрузить их на платформы (Reels/Shorts).
- **Confirmed Decision 3 (Smart Face-Centering Auto-reframe 9:16)**: Вместо жесткого статического кадрирования по центру (`crop=ih*(9/16):ih`) внедряется динамический расчет горизонтального смещения (`x_offset`): определение положения лица/главного персонажа в кадре для центрирования окна 9:16 на говорящем герое (с плавным сглаживанием панорамирования без тряски).
- **Confirmed Decision 4 (Стабильность UI и IPC отмена)**: Устранение `handleCancel is not defined` в `ProgressDisplay.svelte`, реализация бэкенд-команды `cancel_pipeline` с рассылкой прерывания через `broadcast::Sender<()>` и системный `temp_dir` для рабочих аудиофайлов.

### 1. Overview & Core Concept

- **Что делает приложение**: Настольная студия видеомонтажа, превращающая горизонтальные видеоматериалы (сериалы, стримы, подкасты, летсплеи) в готовые вертикальные ролики 9:16 с фокусом на лицах персонажей, сгенерированными субтитрами и чистой структурой файлов.
- **Целевая аудитория**: Видеомонтажеры, контент-мейкеры, SMM-специалисты и переводчики/дабберы (включая работу с кириллическими путями в директориях вроде Яндекс.Диска).
- **Ключевая ценность**: Полная локальная автономность, высокое качество нарезки по звуковым пикам и динамике, аккуратное центрирование персонажей и мгновенная готовность клипов к публикации.

### 2. User Experience & Visual Design

#### Ключевые пользовательские сценарии

1. **Импорт видео**:
   - Перетаскивание или выбор локального файла (например, `...\[3 серия] Военная хроника.mkv`).
   - Отображение честного размера в МБ/ГБ (исправление ошибки `0 МБ` через запрос метаданных файловой системы) и точного хронометража.
2. **Анализ и умный прогресс**:
   - Запуск пайплайна с детализацией по суб-этапам (FFmpeg конвертация, Whisper ASR, аудио-пики, детекция смены сцен и поиск лиц).
   - Кнопка «Отменить операцию» в любой момент останавливает процессы без падения Svelte и возвращает интерфейс в исходное состояние.
3. **Таймлайн с предварительным просмотром кропа**:
   - На шкале времени появляются клипы-кандидаты с названиями и превью центрирования.
   - Пользователь может подтвердить или подправить таймкоды.
4. **Результат в папке проекта**:
   - По нажатию «Экспортировать клипы» создается папка проекта:
     ```
     📁 [3 серия] Военная хроника_Проект/
     └── 📁 Готовые клипы/
         ├── Клип 01 [00m28s - 00m43s].mp4
         ├── Клип 02 [01m28s - 01m43s].mp4
         └── Клип 03 [02m15s - 02m45s].mp4
     ```
   - Кнопка «Открыть папку с клипами» прямо в интерфейсе открывает проводник Windows для моментальной загрузки в соцсети.

### 3. Key Product Decisions & Trade-Offs

- **Ограничение размера GitHub CI (< 2 ГБ) и поставка CUDA**:
  - *Решение*: В GitHub Actions workflow и скриптах подготовки скачиваются только необходимые бинарники Whisper с минимальным набором cuBLAS DLL (v12.2), а также легковесная модель `ggml-base.bin` (~148 МБ). В `tauri.conf.json` размер итогового пакета строго контролируется: не пакуются тестовые дампы и временные распакованные архивы.
  - *Итог*: Размер инсталлятора Windows NSIS составит менее 500 МБ, что полностью исключает превышение лимита в 2 ГБ.
- **Smart Face-Centering (Умный кроп 9:16)**:
  - *Решение*: При подготовке вертикального кадра 9:16 горизонтальное положение окна кадрирования $X$ вычисляется на основе анализа ключевых кадров отрезка (поиск координат лица говорящего персонажа):
    $$\text{Crop Filter: } \texttt{crop=w=ih*(9/16):h=ih:x=clamp(X_{face} - w/2, 0, iw - w):y=0}$$
    Если лицо не обнаружено или находится по центру, используется стабильный центр кадра. Для динамичных сцен применяется сглаживание смещения, чтобы исключить рывки камеры.
- **Структурированная файловая система проекта**:
  - *Решение*: Вся работа организуется вокруг папки проекта:
    1. Промежуточные данные (сырые WAV 16kHz) пишутся в `std::env::temp_dir()` и удаляются автоматически.
    2. Готовые MP4 рендерятся напрямую в поддиректорию `Готовые клипы/` внутри папки проекта.
    3. Имена файлов формируются с ведущими нулями и минутно-секундными таймкодами: `Клип 01 [01m24s - 01m54s].mp4`.
- **Безопасная работа с путями (кириллица, пробелы, скобки `[` и `]`)**:
  - *Решение*: Команды передаются через `Command::args` списком отдельных параметров. В фильтре `-vf` субтитры подключаются через безопасное экранирование спецсимволов или размещаются во временном файле без спецсимволов в имени пути.

### 4. Technical Architecture & Data Strategy

#### Схема пайплайна и файловой структуры

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Tauri Svelte 5 Frontend                         │
│  ┌───────────────────────┐                    ┌─────────────────────┐  │
│  │   FileUpload.svelte   │                    │ProgressDisplay.svelte│ │
│  │  (честный размер МБ)  │                    │(фикс handleCancel)  │  │
│  └───────────┬───────────┘                    └──────────┬──────────┘  │
│              │                                           │             │
│              ▼                                           ▼             │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │              pipelineStore (состояние, логи, отмена)             │  │
│  └───────────────────────────────────┬──────────────────────────────┘  │
└──────────────────────────────────────┼─────────────────────────────────┘
                                       │ Tauri IPC
┌──────────────────────────────────────▼─────────────────────────────────┐
│                       Rust Backend (src-tauri)                         │
│                                                                        │
│  [1. commands.rs] ──► cancel_pipeline / get_video_metadata             │
│                                                                        │
│  [2. audio/whisper.rs]                                                 │
│       ├── Временный WAV в std::env::temp_dir()                         │
│       └── Whisper CUDA + whisper.dll / ggml.dll / cublas               │
│                                                                        │
│  [3. analyzer.rs: Двухфакторный расчет хайлайтов]                     │
│       ├── Фактор 1: Пики громкости и речевой активности (astats)       │
│       └── Фактор 2: Смена планов FFmpeg (gt(scene,0.4))                │
│                                                                        │
│  [4. render.rs: Smart Face-Centering Auto-Reframe]                     │
│       ├── Определение координат лица персонажа X_center               │
│       ├── crop=w=ih*(9/16):h=ih:x=X_center:y=0 + scale=1080:1920      │
│       └── Вшивание субтитров с безопасным экранированием путей         │
│                                                                        │
│  [5. Создание структуры папок проекта]                                 │
│       ├── <ПапкаВидео>/[Название]_Проект/                             │
│       │   └── Готовые клипы/Клип 01 [00m15s - 00m45s].mp4             │
│       └── Очистка std::env::temp_dir()                                 │
└────────────────────────────────────────────────────────────────────────┘
```

#### Порядок реализации по этапам

1. **Этап 1: Исправление краша UI и IPC команды отмены**:
   - Добавление `handleCancel` в `ProgressDisplay.svelte` с защитой try/catch.
   - Реализация и регистрация команды `cancel_pipeline` в Rust (`commands.rs`, `main.rs`).
   - Корректировка получения размера видео в `FileUpload.svelte` и `commands.rs`.
2. **Этап 2: Подготовка Whisper CUDA Sidecar и контроль размера пакета (< 2 ГБ)**:
   - Обновление `download-resources.cjs` и `build.rs`: распаковка и копирование `.dll` зависимостей (`whisper.dll`, `ggml.dll`, `cublas64_*.dll`, `cudart64_*.dll`, `SDL2.dll`) в `resources/`.
   - Включение `"resources/*"` в `tauri.conf.json`.
   - Очистка временных архивов при сборке для гарантии компактности билда в GitHub Actions.
3. **Этап 3: Двухфакторный алгоритм поиска хайлайтов**:
   - Внедрение комбинированного анализа в `analyzer.rs`: аудио-энергия (громкие/эмоциональные реплики) + детекция смены сцен FFmpeg при отсутствии речи или пустых субтитрах.
4. **Этап 4: Smart Face-Centering и нарезка в папку проекта**:
   - Автоматическое создание директории проекта и подпапки `Готовые клипы/`.
   - Расчет позиции лица/персонажа для центрирования при кропе 9:16.
   - Человекочитаемые имена файлов: `Клип XX [XXmXXs - XXmXXs].mp4`.
   - Надежное экранирование кириллических путей и скобок `[` `]`.
