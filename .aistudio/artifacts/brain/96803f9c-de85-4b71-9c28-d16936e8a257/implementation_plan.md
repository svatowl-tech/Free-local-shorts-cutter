# План исправлений для версии 2.0.49

## Выявленные проблемы в логе v2.0.48:
1. **Галлюцинации и шаблонные отказы Vision AI (Moondream2)**:
   - В 8 из 15 кадров модель отвечала фразами отказа: `"I'm sorry, but I can't help you."`, `"I'm not a real assistant..."`, `"I'm sorry, I'm sorry..."`.
   - Ответы не фильтровались, приводили к необоснованному начислению бонусов (0.94 -> 0.97) и засорению описания сцены.
2. **Смещение длительности клипов к 21–23.5 секундам**:
   - `max_ceiling` составлял `max_dur + 3.8` (до 23.8с), а штраф за отклонение от цели 15с был слабым (`0.18`), из-за чего окна почти всегда раздувались до максимума.
3. **Ошибки субтитров (Whisper)**:
   - Заикания с висячей запятой: `«Г, госпожа Бреслий!»`.
   - Слипшиеся слова токенизации: `«недостаточносил»`.
   - Серии точек: `«....»`.
4. **Неравномерный охват сцен**:
   - Искусственный коэффициент `pos_ratio >= 0.25` занижал сцены до 05:55.

## Реализованные исправления (v2.0.49):
- [x] **`src-tauri/src/analyzer.rs`**:
  - Промпт VQA упрощен до нейтрального: `Describe what is visible in this frame in one concise sentence.` (исключает триггеры отказа).
  - В `parse_vision_description_and_bonus` добавлен строгий фильтр отказов и повторов (`i'm sorry`, `can't help`, `not a real assistant`, `don't know what to do`, `sorry` > 1).
  - При отказе бонус не начисляется, описание сцены не засоряется.
  - Удален искусственный перекос `pos_ratio >= 0.25`, лимит кандидатов адаптирован под длину видео.
- [x] **`src-tauri/src/pipeline/orchestrator.rs`**:
  - `max_ceiling` уменьшен до `max_dur + 1.2` (максимум ~21.2с при цели 15с).
  - Штраф `dist_penalty` увеличен до `0.70`, обеспечивая плотное центрирование вокруг целевой длительности (13–17с).
- [x] **`src-tauri/src/whisper.rs`**:
  - Добавлена функция `fix_common_whisper_glued_words` для разделения слипшихся слов (`недостаточно сил`, `не могу`, `всё ещё`).
  - Добавлена функция `fix_whisper_stutters` для очистки артефактов заикания (`Г, госпожа` -> `Госпожа`).
  - Нормализованы многоточия и пунктуационные артефакты.
- [x] **Обновление версий**:
  - `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` обновлены до 2.0.49.
