# 🎬 Video Cutter Pro — Локальный ИИ-генератор Shorts, Reels и TikTok

Кроссплатформенное десктопное приложение на базе **Tauri 2 (Rust + SvelteKit)** для автоматической нарезки длинных видео, фильмов, сериалов, аниме и подкастов на готовые вертикальные ролики (**Shorts / Reels / TikTok, 9:16, 1080×1920**) с использованием 100% локальных нейросетей (**Whisper.cpp**, **LLaMA.cpp / GGUF LLM**, **Qwen2-VL**, **Ollama**) и мультимедийного конвейера **FFmpeg**.

## 🔥 Что реализовано в актуальной версии (v2.0.33)

### 1. 🗣️ Умная нарезка по законченным фразам и диалогам (10–20 секунд)
- **Настраиваемый лимит количества клипов (от 1 до 30 шт.)**: вместо жёсткого ограничения всегда ровно в 10 штук пользователь может задать желаемый лимит через удобный слайдер в настройках. Приложение отбирает **только действительно качественные моменты выше порога интенсивности**, не «высасывая из пальца» лишние клипы на спокойных видео, и находя до 30 ярких сцен на длинных динамичных фильмах и сериях.
- **Гибкое адаптивное окно длительности**: вместо жёсткого отсечения ровно по 15.0 секунды (которое обрывало слова на полуслове) алгоритм подбирает естественную длину каждого клипа в диапазоне **от 10 до 20 секунд** (`целевая ± 5с`).
- **Контроль целостности предложения (Начало -> Конец мысли)**:
  - клип гарантированно открывается с начала нового предложения (`is_sentence_start`) — без старта со строчной буквы или оторванного союза-продолжения (*«Поэтому...»*, *«Потому что...»*, *«И в моих...»*);
  - финал клипа автоматически дотягивается до завершающего знака препинания (`.`, `!`, `?`, `…`), чтобы ни одна фраза не обрывалась в воздухе.
- **Защита от сюжетных разрывов внутри одного шортса**: детектор пауз (`has_internal_story_break`) запрещает склеивать в один клип реплики из разных сцен, разделённых длинной тишиной или музыкальным проигрышем.
- **Учёт скорости чтения**: фильтр плотности речи отбраковывает пустые крики и сверхбыструю нечитаемую скороговорку.

### 2. 🎙️ Распознавание речи Whisper.cpp + Многоступенчатая реставрация субтитров
- **Автовыбор старшей установленной модели**: если в системе скачана `Whisper Small Q5`, `Medium Q5` или `Large-v3-Turbo`, движок автоматически выбирает её вместо базовой `ggml-base.bin` для максимальной точности русской речи.
- **Анти-галлюцинационный профиль инференса**: запуск `whisper-cli` с жёсткими порогами энтропии и вероятности (`-et 2.4`, `-lpt -1.0`, `-nth 0.60`, `-mc 64`, `-ml 52`), подавляющими зацикливание текста поверх музыки опенингов и эндингов.
- **Глубокая санитарная очистка и склейка SRT (`sanitize_srt_file`)**:
  - автоматическое удаление звуковых и технических ремарок (`[музыка]`, `ИНТРИГУЮЩАЯ МУЗЫКА`, титров редакторов и корректоров субтитров);
  - сжатие бесконечных растянутых гласных и криков (*«Ооооооооо...»* -> *«Ооо!»*, *«Ха-ха-ха-ха...»* -> *«Ха-ха-ха!»*);
  - удаление как одиночных дублей, так и **многострочных блочных повторов (`ABAB`)** (когда Whisper дважды подряд повторяет блок из 2–6 реплик диалога) и слитных эхо-повторов;
  - **морфологическая реставрация разорванных слов и хвостов фраз (`repair_split_words_and_orphans`)**: автоматическое сшивание слов, разрезанных лимитом строки на границе соседних таймкодов, и присоединение коротких оторванных концовок (1–3 слова) обратно к основному предложению.
- **Кэширование субтитров в папке проекта**: готовый очищенный файл сохраняется по пути `<Видео>_Проект/Субтитры/<Видео>_Субтитры.srt` и мгновенно переиспользуется при повторной нарезке.

### 3. 🧠 Семантический анализ текста (Локальные GGUF LLM + Ollama + Встроенный NLP)
- **Пакетный анализ реплик через `llama-cli` или `Ollama`**:
  - каждая реплика размечается структурными тегами `[НАЧАЛО ФРАЗЫ]` / `[ПРОДОЛЖЕНИЕ]` и `[КОНЕЦ ФРАЗЫ]` / `[НЕ ЗАВЕРШЕНА]`, чтобы LLM ставила максимальный рейтинг (0.75–0.95) именно ярким законченным мыслям и диалогам;
  - динамический расчёт лимита токенов под размер пакета и строгий парсер JSON-ответов.
- **Умная отказоустойчивость и приоритет моделей**:
  - автоматический выбор лучшей скачанной GGUF-модели (например, `Qwen 2.5 3B Instruct Q4_K_M` вместо устаревшей `qwen-1.5b`);
  - защита от артефактов CUDA FP16: при сбое генерации на выбранной модели движок сначала автоматически пробует другую установленную GGUF-модель на GPU, затем чистый CPU-режим (`CUDA_VISIBLE_DEVICES=""`), а при необходимости бесшовно переключается на встроенный скоростной **NLP-анализатор полных фраз** без потери времени.

### 4. 👁️ Динамическое ведение лиц и смена ракурсов внутри клипа (Smart Face Tracking v2)
- **Полноценное отслеживание внутри ролика (2 FPS)**: вместо выбора одной статичной точки на весь 15-секундный клип рендерер за один быстрый проход FFmpeg извлекает серию кадров `240×135` с шагом **0.5 секунды** по всей длине клипа.
- **2D-детектор головы, глаз и силуэта (`analyze_bmp_frame_2d`)**:
  - ищет компактные 2D-кластеры головы в 3 масштабах (крупный, средний и общий план);
  - комбинирует детекцию реалистичной кожи (YCbCr/RGB) и аниме-кожи с **признаком микроконтраста глаз/ресниц/бровей** и контуров фигуры (благодаря чему уверенно держит в центре кадра даже персонажей в масках и Кайдзю);
  - вычисляет **изоляцию головы от фона** и штрафует глобальные засветы, чтобы стены, небо и вспышки взрывов не уводили камеру в сторону.
- **Переключение на склейках и плавное панорамирование**:
  - при резкой смене плана или переключении камеры на другого говорящего персонажа внутри одного клипа окно `9:16` мгновенно перескакивает на новое лицо;
  - если персонаж плавно движется в кадре — виртуальная камера `9:16` плавно панорамирует вслед за ним через динамическое выражение FFmpeg `crop` от времени `t`, масштабируя видео до `1080×1920 (Lanczos)`.

### 5. 📊 Мультимодальный анализ сцен, звука и Менеджер ИИ-моделей
- **Аудио-визуальный скоринг (`analyzer.rs`)**: параллельный поиск визуальных склеек (`scene > 0.3`) и пиков звуковой энергии (`astats` RMS) через FFmpeg + опциональный анализ ключевых кадров через `Qwen2-VL-2B` (`llama-mtmd-cli` при наличии `mmproj`).
- **Встроенный Менеджер ИИ-моделей**:
  - готовые пресеты под конфигурацию компьютера (**Слабый ПК / Без GPU**, **Средний ПК / Оптимальный**, **Мощный ПК / Максимум**);
  - скачивание и удаление весов Whisper (`Tiny`, `Base`, `Small Q5`, `Medium Q5`, `Large-v3-Turbo`), текстовых LLM (`Qwen 2.5 0.5B / 1.5B / 3B`, `Llama 3.2 1B / 3B`, `Gemma 2 2B`) и `Qwen2-VL` прямо из интерфейса приложения в системную директорию `AppData` или локальную папку `models/`.

## 🛠️ Локальная разработка и сборка

### Системные требования:
- **Node.js**: 20 LTS+
- **Rust**: `stable` (`1.77+`)
- **Linux-зависимости (для сборки на Ubuntu/Debian)**:
  `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`, `libasound2-dev`, `patchelf`

### Основные команды:

```bash
# 1. Установка npm-зависимостей
npm install

# 2. Загрузка sidecar-бинарников (FFmpeg, Whisper, LLaMA) и генерация иконок
npm run download:binaries
npm run generate:icons

# 3. Запуск десктопного приложения в режиме разработки Tauri
npm run tauri:dev

# 4. Полная релизная сборка инсталляторов и Portable-архивов
npm run build:all

# 5. Синхронное поднятие версии в package.json, Cargo.toml и tauri.conf.json
npm run version:bump patch
```

```text
│   ├── download-resources.cjs  # Автозагрузка FFmpeg, Whisper.cpp и LLaMA.cpp под целевую ОС

│   └── package-portable.js     # Упаковка Portable-архивов и сбор дистрибутивов
├── src/                        # Фронтенд на Svelte 5 + SvelteKit + Tailwind CSS
│   └── lib/
│       ├── components/         # UI-компоненты (плеер с таймлайном, менеджер моделей, настройки, логи)
│       └── stores/             # Реактивные хранилища состояния конвейера и каталога ИИ-моделей
└── src-tauri/                  # Бэкенд на Rust (Tauri 2)
    └── src/
        ├── pipeline/           # Оркестратор конвейера и умный ранжировщик цельных фраз (10–20с)
        ├── whisper.rs          # Интеграция whisper.cpp, фильтрация галлюцинаций и склейка полуслов
        ├── text_analyzer.rs    # Инференс llama-cli / Ollama и встроенный семантический NLP-движок
        ├── analyzer.rs         # FFmpeg-детектор сцен, RMS-анализ звука и Qwen2-VL Vision
        ├── render.rs           # Smart Face Tracking v2 (2D-трекинг лиц внутри клипа) и рендер 9:16
        └── models.rs           # Менеджер загрузки, проверки и автовыбора локальных моделей ИИ
```
