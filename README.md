# 🎬 Video Cutter Pro v2.3 — Умная нарезка длинных видео на Shorts, Reels и TikTok

Современное кроссплатформенное десктопное приложение на базе **Tauri 2 (Rust + SvelteKit 2 + Tailwind CSS)** для автоматической нарезки длинных видеофайлов (подкастов, стримов, сериалов, аниме, интервью, лекций) на готовые вертикальные ролики (**Shorts / Reels / TikTok, 9:16, 1080×1920**) и горизонтальные хайлайты с использованием 100% локальных нейросетей (**Whisper.cpp**, **LLaMA.cpp / GGUF LLM**, **Qwen 2.5 / Vikhr**, **Ollama**) и мультимедийного конвейера **FFmpeg**.

## ✨ О проекте

**Video Cutter Pro** решает ключевую задачу контент-мейкеров, стримеров, блогеров и SMM-агентств: преобразование многочасовых горизонтальных записей в серию законченных, динамичных и готовых к публикации коротких роликов без ручного монтажа.

Приложение полностью автономно, не требует обязательных платных подписок или облачных ключей, сохраняет 100% приватность исходных материалов на компьютере пользователя и выполняет полный производственный цикл:
1. **Анализ звука и речи**: выявление реплик, интонационных акцентов и эмоциональных пиков.
2. **Семантический отбор фраз**: поиск законченных мыслей без обрывов предложений.
3. **Умное кадрирование 9:16**: непрерывное отслеживание говорящего персонажа и смена ракурсов.
4. **Студия заставок**: добавление прероллов и построллов с плавными фейдерами и размытым фоном.
5. **SMM-сопровождение**: автоматическое составление названий, описаний и тегов в текстовые файлы рядом с каждым роликом.

## 🚀 Ключевые возможности версии 2.3

### 1. 🗣️ Умная нарезка по законченным фразам и диалогам
- **Адаптивное окно длительности (10–20 секунд)**: алгоритм находит естественные границы речи вместо слепой нарезки по фиксированному таймеру.
- **Строгий контроль целостности мысли**:
  - Начало клипа привязано к старту предложения — без оторванных союзов (*«Поэтому...»*, *«И тогда...»*) и фраз со строчной буквы.
  - Конец клипа автоматически дотягивается до завершающего знака препинания (`.`, `!`, `?`, `…`).
  - Детектор сюжетных пауз предотвращает склейку реплик из разных сцен через долгую тишину.
- **Настраиваемый лимит (от 1 до 50 клипов)** и регулируемый порог интенсивности: отбираются только по-настоящему яркие моменты.
- **3 гибких режима работы**:
  - **Автоматический**: конвейер полного цикла от анализа исходника до готовых роликов.
  - **С проверкой**: ИИ находит и дорабатывает лучшие сцены, выносит их на таймлайн для предпросмотра и ручной корректировки, после чего пользователь экспортирует результат в один клик.
  - **Ручной**: свободная разметка клипов на таймлайне с рамкой предпросмотра 9:16.

### 2. 🎙️ Двухконтурная аудио-проверка и санитарная обработка субтитров
- **Инференс Whisper.cpp с защитой от галлюцинаций**: автоматический выбор лучшей установленной модели (`Tiny`, `Base`, `Small Q5`, `Medium Q5`, `Large-v3-Turbo`) с подавлением зацикливаний на музыке и опенингах.
- **Глубокая очистка субтитров (`sanitize_srt_file`)**:
  - Удаление шумовых ремарок (`[музыка]`, титры редакторов).
  - Сжатие протяжных криков и междометий.
  - Устранение циклических дублей и блочных повторов (`ABAB`).
  - Морфологическая реставрация разорванных слов на стыках таймкодов.
- **Повторная аудио-проверка Whisper по готовым клипам**: финальная верификация границ каждого готового шортса для гарантированной защиты от обрезания фраз героев на полуслове.
- **Поддержка внешних субтитров (`.srt`, `.ass`)**: фильтрация реплик по конкретным говорящим персонажам (актуально для аниме, сериалов и подкастов с несколькими гостями).

### 3. 👁️ Smart Face Tracking 9:16 и финальная верификация лиц
- **Внутриклиповое ведение лиц (2 FPS)**: анализ кадров с шагом 0.5 секунды на протяжении всего ролика.
- **2D-детектор головы, глаз и силуэта**:
  - Анализ реалистичной кожи (YCbCr/RGB), аниме-оттенков и микроконтраста области глаз/бровей.
  - Уверенное удержание в кадре персонажей со сложной внешностью, масками или стилизованной анимацией.
  - Учет изоляции объекта от фона и подавление ложных срабатываний на ярких стенах и взрывах.
- **Динамическая камера**: плавное панорамирование за движущимся персонажем и мгновенное переключение при смене планов на монтажных склейках.
- **Финальная верификация лиц в готовом клипе**: если в итоговом вертикальном ролике не зафиксировано ни одного лица, система проверяет оригинальное видео в этом таймкоде и автоматически перекалибровывает кадрирование.

### 4. 🧠 3-ступенчатый ИИ-конвейер и SMM-копирайтинг
- **1-я ступень**: семантический отбор ключевых сцен через локальные модели GGUF (`llama-cli`), `Ollama` или внешний OpenAI-совместимый API.
- **2-я ступень**: дополнительный круг проверки связности и доработки границ фрагментов.
- **3-я ступень (SMM-копирайтер)**: автоматическая генерация броских заголовков, цепляющих описаний и релевантных хештегов с записью отдельных файлов `.txt` рядом с каждым клипом.

### 5. 🎨 Студия заставок (Преролл и Постролл)
- **Оформление роликов**: добавление вступительных и завершающих заставок в форматах 9:16 и 16:9.
- **Адаптивный фон**: режим создания заставки с последним кадром каждого клипа и кинематографичным размытием.
- **Плавные переходы**: настраиваемые аудио- и видео-фейдеры (fade in, fade out, crossfade) без резких скачков громкости и картинки.
- **Экспорт и импорт пресетов**: сохранение готовых шаблонов оформления в переносимый формат `.vcpb` и пакетный предрендер в MP4.

### 6. 🎬 Сборка хайлайтов 16:9 и разговорного видео
- **YouTube Хайлайты 16:9**: автоматическое объединение лучших моментов в единый дайджест с субтитрами.
- **Ток-видео без пауз**: удаление пауз и провисаний между репликами для создания динамичного разговорного видеоряда.

### 7. 📦 Встроенная библиотека моделей и приватность
- **Каталог моделей в один клик**: загрузка и управление моделями распознавания речи (Whisper) и языковыми моделями (Qwen 2.5, Vikhr, LLaMA, Gemma).
- **Профили производительности**: готовые конфигурации для слабых ПК (без дискретной видеокарты), средних систем и мощных рабочих станций с GPU.
- **Полная локальность**: обработка медиа и генерация текстов происходят на вашем устройстве без передачи исходников третьим лицам.
- **Детальный журнал выполнения**: удобный просмотрщик этапов, копирование логов в буфер обмена и экспорт в файл.

## 🛠️ Локальная сборка и запуск для разработчиков

### Системные требования:
- **Node.js**: `20 LTS` или новее
- **Rust**: `stable` (`1.77+`)
- **Системные зависимости Linux (Ubuntu/Debian)**:
  `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`, `libasound2-dev`, `patchelf`

### Пошаговые команды:

```bash
# 1. Клонирование репозитория
git clone https://github.com/svatowl-tech/Free-local-shorts-cutter.git
cd Free-local-shorts-cutter

# 2. Установка зависимостей интерфейса
npm install

# 3. Загрузка sidecar-бинарников (FFmpeg, Whisper.cpp, LLaMA.cpp) под текущую ОС
npm run download:binaries

# 4. Генерация набора иконок приложения
npm run generate:icons

# 5. Запуск в режиме разработки (Hot-reload фронтенда + Rust-бэкенд)
npm run tauri:dev

# 6. Проверка типов и линтинг интерфейса
npm run check
npm run lint

# 7. Полная релизная сборка дистрибутивов и архивов
npm run build:all
```
